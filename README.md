# 🍽️ Cafe21 – Online Restaurant Management Mobile App  

**Cafe21** is a powerful **Restaurant & Cafe Management System** built with **Flutter**, integrated with **Firebase** for cloud storage, and compatible with **Android Bluetooth POS Printers**.  
Designed with a **clean MVC architecture**, this app offers **role-based management**, smooth performance, and an intuitive user experience — making restaurant operations easier than ever.  

---

## 🚀 Features  

- ✅ **Restaurant & Cafe Management System** – Manage orders, staff, and menus with ease  
- ✅ **Role-Based App Management** – Separate access for Admin, Waiters, and Users  
- ✅ **Clean Code & MVC Pattern** – Organized, maintainable, and scalable code structure  
- ✅ **Fully Customizable** – Easy to modify UI, features, and configurations  
- ✅ **Bluetooth POS Printer Support** – Print invoices and receipts directly via Android Bluetooth printers  
- ✅ **Firebase Cloud Database** – Real-time data sync and secure cloud storage  
- ✅ **Google Firebase Authentication** – Secure login & registration  
- ✅ **Admin & User Login** – Different dashboards for different roles  
- ✅ **Detailed Order Management** – Track, update, and complete orders in real-time  
- ✅ **Role-Based User Profile** – Custom dashboard based on user type  
- ✅ **Sales Analytics** – View daily, weekly, and monthly sales history  
- ✅ **Top Performers Insights** – See most selling items and most serving waiters  

---

## 🛠️ Tech Stack  

- **Flutter** – Cross-platform mobile app framework  
- **Firebase** – Authentication & Cloud Database  
- **Bluetooth POS Printing** – Android compatible printers  
- **MVC Architecture** – For clean, organized code
